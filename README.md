# KeyCampus  
  KeyCampus é um projeto acadêmico desenvolvido com fins de prática e aprendizado, voltado para o gerenciamento de salas, usuários e agendamentos em ambientes educacionais.  
  A proposta do sistema é facilitar a organização e o controle de espaços, permitindo acompanhar o status das salas, realizar agendamentos e gerenciar usuários através de uma interface desktop intuitiva.  
  A aplicação foi construída utilizando Java e JavaFX, permitindo aplicar na prática conceitos de programação orientada a objetos, integração com banco de dados e desenvolvimento de interfaces gráficas.  

## Funcionalidades  
* Cadastro e gerenciamento de salas
* Controle de status das salas
* Cadastro de usuários * Sistema de agendamentos
* Dashboard com informações do sistema
* Operações CRUD completas
* Interface gráfica desenvolvida com JavaFX

## Tecnologias Utilizadas  
* Java
* JavaFX
* FXML
* CSS
* SQLite
* JDBC

## Conceitos Aplicados
  Durante o desenvolvimento do projeto foram praticados conceitos como:  
* Programação Orientada a Objetos
* Arquitetura MVC
* Integração com banco de dados
* Relacionamentos SQL
* Manipulação de eventos
* Desenvolvimento de interfaces gráficas
* Organização em camadas (Model, Controller e DAO)

## Objetivo do Projeto  
  O principal objetivo do KeyCampus é servir como projeto de prática e evolução técnica, aplicando conhecimentos de desenvolvimento desktop e banco de dados em um cenário próximo de uma aplicação real.
